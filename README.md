# 墨锭试磨室

运行：

```bash
npm start
```

访问 `http://localhost:3037`。数据保存在 `data/ink-stick-testing.json`（可用环境变量
`DATA_FILE` 指定别的文件，`PORT` 改端口）。

## 受控试磨组

在单锭试磨之外，新增三锭受控试磨组，用来比较**同一烟料、同一胶比、同一年限**的三锭：

- **建组即锁定**纸样、加水量、室温三个条件，三锭的烟料/胶比/年限不一致不能建组。
- 之后录入结果**每次最多只改一个条件**；改两项或条件/评分/沉淀缺失的记录会保留但判为
  无效，不参与判定（页面会标红说明原因）。
- 每锭只取**最近一条有效结果**；三锭评分差不超过 8 分且沉淀等级相同时，组内显示
  **平均评分**和**最突出的一锭**；否则明确标注不给结论及原因（分差过大/沉淀不一致/等待结果）。
- **条件更正**（更正锁定条件或更正某条结果）后，本组旧结论立即作废：全部记录重新判定
  有效性并整组重算，作废与重算都写入组内履历，记录本身不删除。
- 三锭结果在页面上**并排展示**。

## 模块分工

- `groups.js`：分组判定（建组校验、单条记录有效性、每锭最近有效结果、组结论），纯函数。
- `store.js`：记录保存。写操作经串行锁排队，临时文件 + 原子重命名写盘，多人同时提交
  不会互相覆盖。
- `page.js`：页面并排展示。
- `server.js`：HTTP 路由与装配。
